# 3DS Jingles for Cocoon

272 MP3 clips from the supplied collection, with an index following the official Cocoon repository template. Audio bytes and paths are unchanged. Catalogue titles omit trailing revision labels and (new).

## Upload to GitHub
1. Extract this ZIP on your PC.
2. Create a GitHub repository named `3ds-jingles`.
3. Upload `index.json`, `README.md` and the complete `audio` folder to the repository root. Upload the extracted contents, not this ZIP. If the browser limits the number of files per upload, upload audio in batches of fewer than 100 files into an `audio` folder.
4. Commit the uploads. The repository root must contain index.json and audio/ directly.
5. In Cocoon's Jingle Repositories settings, add YOUR-GITHUB-USERNAME/3ds-jingles.
6. On Cocoon 3.0.5 or later, open Library & Data > Scrape and look for jingles after configuring the repository. Select your 3DS games and scrape missing jingles.
7. For unmatched games, select the game, press Y > Edit, and use the jingle picker to search manually.

The standard documented repository flow needs a repository Cocoon can read. Private-repository authentication has not been verified. Only publish audio you have permission to distribute.

This pack is prepared but has not been uploaded to GitHub or tested on a Thor. Matching depends on game titles and the Cocoon version; it does not cover every 3DS game.
